# Account FAQ

**How do I change my shipping address after placing an order?**
If the order hasn't shipped yet (status is PROCESSING), a support agent can
update the shipping address. Once an order is SHIPPED, the address cannot
be changed - the customer will need to contact the carrier directly or
arrange a redelivery once it arrives.

**How do I cancel an order?**
Orders can be cancelled for a full refund only while status is PROCESSING.
Once an order is SHIPPED, it cannot be cancelled - the customer should wait
for delivery and then request a return per the Refund Policy.

**Do you offer price matching?**
No, price matching is not offered. Price changes after an order is placed
do not retroactively apply to that order.

**How do I contact a human support agent directly?**
Any request that this assistant cannot resolve - or that requires manual
approval, like a large refund or an out-of-policy exception - is
automatically flagged for a support agent to follow up within one business
day.
